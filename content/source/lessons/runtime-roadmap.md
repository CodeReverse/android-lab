这个专题把“解释程序如何运行”作为共同主线。它服务 Java/Kotlin 与 Android 资深岗位，不把 HotSpot 的实现细节当成 ART，也不把会背名词当成理解原理。各篇正文都可独立阅读，进度与练习由设置决定。

## 把机制连到实际故障

页面退出后对象仍被保留时，沿 Handler 队列、回调捕获和 GC Roots 找到生命周期错位；内存继续增长时，再区分 Java 堆、native 资源与线程数量。

并发错误先确定不变量，再用 JMM 分析发布与读取，用锁或原子协议保护复合操作。出现 ANR 时，把这些同步关系画成等待链。底层知识的作用是解释因果，单独背诵 API 不足以定位问题。

每篇先讲概念和组成，再用一次执行说明协作过程，最后展开实现、边界和验证。正文是连续讲解，文末的面试提炼用于检查理解。公共契约先于版本实现，JVM 规范、HotSpot 与 ART 分开讨论。
